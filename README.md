# Bus-Seat-Availability-Model
🚌 Real-Time Bus Seat Availability Detector using YOLOv8
A computer vision-based application that uses YOLOv8 to detect and count people in a bus, estimating the real-time seat availability. Built as a class project to demonstrate applied machine learning, data analytics, and dashboarding skills.

## 💼 Project Relevance
This project showcases a practical business analytics application where real-time object detection is used to support operational efficiency and decision-making—skills highly relevant to roles in business analytics, data-driven product management, and transportation systems optimization.

## 🔍 Features
📷 Real-time detection of passengers using webcam

🧠 Powered by YOLOv8 object detection model

📊 Live display of seat availability from total capacity

🖥️ GUI built with Tkinter for interactive monitoring

🛠️ Easy-to-extend architecture for other vehicle types or custom analytics

## 🧪 Tech Stack
Python

YOLOv8 for person detection

OpenCV for video processing

Tkinter for GUI

PIL for image rendering

## 🛠️ How It Works
Loads a YOLOv8 pre-trained model.

Captures video feed using a connected webcam.

Detects people in the frame.

Calculates number of available seats from a predefined total.

Displays the occupancy and availability on a real-time GUI.

## 📊 Business Analytics Angle
This project is not just a technical exercise—it's a demonstration of business analytics in action:

Data-Driven Decision Making: Real-time detection leads to optimized resource allocation (e.g., dynamic rerouting, occupancy-based scheduling).

Operational Efficiency: Helps reduce overcrowding and improve user experience.

Scalability: Adaptable to trains, metros, offices, and public venues.
